## About this repository

This repository is the shared home for course resources in **COMP 271-002: Data Structures I**, taught by **Dr. Karima Ennaoui** in Fall 2026. Throughout the semester, it will collect resources meant to support you as you build on your COMP 170/163 foundations and grow into object-oriented design, fundamental data structures, algorithm analysis, and professional practices like testing and version control.

Sakai remains the **authoritative source** for the syllabus, graded assignments, deadlines, and official announcements. This repository is a companion resource: a place to pull in-class notes, working code, review examples at your own pace, and see how implementations evolve as we cover new data structures across the semester.

